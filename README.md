# 🚀 SCESI Postulaciones 2026
### 💻 Fase 2: Dominando Git y GitHub

> Un repositorio diseñado para la evaluación del manejo de control de versiones, flujos de trabajo colaborativos y estructuración de maquetación web.

---

## 🎯 Propósito del Repositorio

Esta fase de la postulación está orientada a demostrar competencias técnicas esenciales para el trabajo en equipo dentro de la sociedad científica:
* **Control de Versiones:** Uso fluido de ramas (*branches*), *commits* atómicos y resoluciones de conflictos.
* **Colaboración Open Source:** Creación de *Forks* y *Pull Requests* bien documentados.
* **Fundamentos Web:** Despliegue de una *landing page* funcional y limpia.

---

## 🛠️ Stack Tecnológico

La base de este proyecto se mantiene ligera, nativa y sin frameworks pesados para evaluar el dominio de los fundamentos:

| Tecnología | Rol en el Proyecto |
| :--- | :--- |
| **HTML5** 🟠 | Estructuración semántica del DOM. |
| **CSS3** 🔵 | Estilos, variables globales y diseño responsivo (*Normalize.css* integrado). |
| **JavaScript** 🟡 | Lógica del cliente e interactividad. |
